# 📊 Sales Prediction Using Python

## 📌 Overview

This project uses Machine Learning to predict product sales based on advertising expenditures across TV, Radio, and Newspaper channels. It demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), model building, evaluation, and prediction using Linear Regression.


## 🎯 Objectives

- Analyze the relationship between advertising budgets and sales.
- Perform data preprocessing and exploratory data analysis.
- Build a Linear Regression model for sales prediction.
- Evaluate the model using performance metrics.
- Visualize insights from the dataset.
  

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook


## 📂 Dataset

The dataset contains the following features:

- **TV** – Advertising budget spent on TV.
- **Radio** – Advertising budget spent on Radio.
- **Newspaper** – Advertising budget spent on Newspaper.
- **Sales** – Product sales (Target Variable).


## 📋 Project Workflow

1. Import Libraries
2. Load Dataset
3. Data Preprocessing
4. Exploratory Data Analysis (EDA)
5. Correlation Analysis
6. Feature Selection
7. Train-Test Split
8. Model Training using Linear Regression
9. Model Evaluation
10. Sales Prediction
11. Data Visualization


## 📈 Model Evaluation

The model is evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)


## 📊 Key Insights

- TV advertising has the highest impact on sales.
- Radio advertising positively influences sales.
- Newspaper advertising has a relatively smaller effect.
- Linear Regression provides reliable sales predictions.


## 🚀 How to Run

1. Clone the repository.
2. Install the required libraries:
       - Pandas
       - Numpy
       - Matplotlib
       - Seaborn
       - Scikit-learn
4. Open the Jupyter Notebook.
